# AGENTS.md

This project is UICrafter.

UICrafter is a VS Code extension for generating UI templates.

Use TypeScript.

Keep code organized.

Use one shared template system for web and mobile.

Use platform specific code generators.

Keep generated code readable.

Prefer simple extension APIs.

Do not add a backend unless explicitly asked.

Do not add paid APIs.

Do not overengineer.

Make the extension easy to use.

Run compile checks before finishing.
